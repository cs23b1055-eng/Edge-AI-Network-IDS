## 4. Data quality

- Missing values: 1,358 (all in `Flow Bytes/s`).
- Infinite values: 4,376 (`Flow Bytes/s` 1,509, `Flow Packets/s` 2,867) - produced by zero-duration flows.
- Exact duplicate rows: 308,381 (10.9%); 2,522,362 remain after de-duplication.
- Negative values in columns that should be non-negative: Flow Duration, Flow Bytes/s, Flow Packets/s, Flow IAT Mean, Flow IAT Max, Flow IAT Min, Fwd IAT Min, Init_Win_bytes_forward, Init_Win_bytes_backward, Fwd Header Length, Bwd Header Length, Fwd Header Length.1, min_seg_size_forward (CICFlowMeter artefacts; `Init_Win_bytes_*` = -1 legitimately means 'no TCP window seen').
- Constant columns: Bwd PSH Flags, Bwd URG Flags, Fwd Avg Bytes/Bulk, Fwd Avg Packets/Bulk, Fwd Avg Bulk Rate, Bwd Avg Bytes/Bulk, Bwd Avg Packets/Bulk, Bwd Avg Bulk Rate.
- The raw header contains `Fwd Header Length` twice (pandas renames the second `.1`; the values are identical).
- The raw header has leading spaces in names; one label contains a mis-encoded en-dash (`Web Attack ï¿½ ...`) which is normalised.

## 5. Leakage analysis and split strategy

- **No timestamp, IP or flow-ID columns** exist, so a chronological or session-grouped split is impossible. Rows cannot be tied to sessions.
- **Duplicates** would leak identical rows between train and test, so exact duplicates are removed *before* splitting (test: `test_deployed_preprocessing_matches_training_pipeline` checks that splits are disjoint).
- **Day confounding:** each attack family appears on one day only (e.g. DoS Wednesday, PortScan/DDoS Friday), so a day-based split would leave whole classes absent from training. A stratified random 70/15/15 split (seed 42) is used and its limitation is stated: neighbouring flows from one attack burst are correlated, so random-split scores are *optimistic* relative to unseen environments. To quantify generalisation a held-out-attack-family experiment (train without PortScan and DDoS) is reported in `results/experiments.json`.
- **`Destination Port`** is a potential shortcut (attacks hit fixed ports in the testbed); an ablation without it is reported.
- Preprocessing statistics (median, mean, std) are fitted on the training split only.

## 6. Feature selection (57 of 78)

Kept: features a packet sniffer can compute (counts, payload lengths, IATs, flags, header lengths, window sizes, rates). Removed: 8 constant columns, the duplicate header column, `Subflow *` (identical to totals), `Active/Idle *` (need CICFlowMeter's activity-timeout state), `Bwd PSH/URG` (constant). Full list in `python_network/preprocessing.py`.

## 7. Labels used

- Binary: BENIGN vs ATTACK (all 14 attack labels, including Infiltration and Heartbleed).
- 7-class: BENIGN, DoS (Hulk/GoldenEye/slowloris/Slowhttptest), DDoS, PortScan, Brute Force (FTP/SSH-Patator), Web Attack (3 kinds), Bot. Infiltration and Heartbleed are excluded from this task (47 rows: cannot be learned or fairly evaluated) and the system makes **no claim** to categorise them.

## 9. Suitability

Suitable: labelled flow-level features, broad attack coverage, large size. Caveats: a single synthetic testbed from 2017, no raw PCAPs (so the live feature extractor cannot be validated byte-for-byte against the dataset's CICFlowMeter output), and heavy class imbalance.
